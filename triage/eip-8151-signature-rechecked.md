## Summary

These contracts check a signature again after someone else has acted on it: channel states, fraud proofs, settlements, committee results. 36 code families, 21,917 addresses, $857k held, 645 recoveries in the study's two-week window. Rows by rating: CRITICAL 32, HIGH 3, LOW 1. 6 rows were checked on a real transaction; the others were read from source, judged from bytecode or placed by measured rules (each row's note says which).

## Mechanism

PQ-15. The second check reads the signer's account code at that time. Once that account has real code it recovers no address: the party that relied on the signature loses, and a signer can cause it on purpose by migrating between the two steps.
