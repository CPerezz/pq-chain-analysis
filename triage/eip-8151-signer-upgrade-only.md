These contracts accept signatures from a key that no function replaces; only an upgrade of the code does. 156 code families, 1,352 addresses, $18k held, 136 recoveries in the study's two-week window. Rows by rating: HIGH 131, LOW 25. 18 rows were checked on a real transaction; the others were read from source, judged from bytecode or placed by measured rules (each row's note says which).

## Mechanism

PQ-17. Once that key's account has real code, the signed functions stop until the admin upgrades.
