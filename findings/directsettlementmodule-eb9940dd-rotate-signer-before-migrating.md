## Summary

`DirectSettlementModule` at `0xeb9940dd4a219bb5a4d29467587837d1f371daa8`. It accepts signatures from a key that a function can replace; the holder rotates it before the account takes code.

## Mechanism

PQ-17. Once that key's account has real code its signatures stop counting; its holder rotates first, or the owner afterwards.

## Evidence

- How it was placed: bridge cosignature: the signer must be approved in the signers registry; an empty cosignature skips the check / SignatureLib.verify: empty signature means pre-signed on chain; an address without code…. Read (function text).
