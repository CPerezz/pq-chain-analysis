## Summary

`LateDAO` at `0x9717e477cc5869a4a228361492b9bf7b8db58582`. It accepts signatures from a key that a function can replace; the holder rotates it before the account takes code.

## Mechanism

PQ-17. Once that key's account has real code its signatures stop counting; its holder rotates first, or the owner afterwards.

## Evidence

- How it was placed: the signer is one key kept in storage; functions replace it (updateBypassSignatureChecking, updateSignerAddress). Whoever holds it must replace it before that account takes code. Rule: stored-key.
