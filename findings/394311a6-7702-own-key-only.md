## Summary

unnamed 7702 delegate: EIP-7702 delegate logic whose signed path accepts only the account's own key (recovered == address(this)). Under EIP-8151 it fails only if the account later holds real code.

## Mechanism

PQ-20. As a 7702 delegation they keep working: EIP-8151 exempts delegation indicators. An account that takes this logic as real code can no longer authorise anything, and with code it cannot send transactions (EIP-3607), so what it holds is locked.

- How it was placed: 7702 delegate: the recovered address must be the account itself. Bytecode and names. Executed: a real transaction reverts once the account holds this logic as real code.

## Impact and exposure

- Value held at block 26,438,999: $111,883 (ETH and 49 priced tokens, over 7 addresses).

## Remediation

Keep the 7702 delegation, or re-delegate to logic that accepts the account's key while it has code / ERC-1271.
